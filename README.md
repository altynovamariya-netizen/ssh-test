# Работа с серверами и протокол удаленного управления SSH

Все шаги выполнены на macOS:

1. **Генерация ключей**: Создана новая пара ключей типа ed25519 с паролем (passphrase).
2. **Добавление на GitHub**: Публичный ключ успешно добавлен в настройки аккаунта.
3. **Проверка**: Команда `ssh -T git@github.com` выдала приветствие (аутентификация пройдена).
4. **Работа с репозиторием**: Репозиторий склонирован по SSH, сделан коммит и выполнен `git push` без ввода пароля от GitHub.
